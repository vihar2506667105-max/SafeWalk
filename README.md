# SafeWalk — Women Safety Companion

A premium-style, dual-role emergency simulation app for hackathon demos.

## Highlights
- Dual interfaces (Woman + Handler) rendered side-by-side
- Live simulated route and safety zones
- SOS emergency workflow with real-time sync via `BroadcastChannel`
- Escort requests, guardian active toggle, anonymous local chat, suspicious activity reporting
- Simulation mode auto-runs full rescue sequence
- Dark/light theme, micro-interactions, and glassmorphism-inspired UI

## Run locally
```bash
npm install
npm run dev
```

> If install is blocked in your environment, open `index.html` after integrating dependencies through an approved registry mirror.
